# ΦBioMesh

**A resonant biosphere network laboratory.**

An open, browser-based experiment in bio-integrated sensing, adaptive low-power data routing, energy-aware communication, and responsive light.

**Research boundary:** The virtual plants, their electrical signals, microbial harvesting, batteries, and communication links are simulated. Data packets travel over a **modeled low-power radio mesh**, not through actual trees, fungal networks, or people. This project does not claim that living organisms can replace utility-scale power infrastructure.

## Mission
Explore how living ecosystems can inform infrastructure without treating life as a disposable fuel source.

## Roadmap
- Phase 1: interactive nine-node browser simulation and GitHub Pages
- Phase 2: reproducible experiments, telemetry export, routing benchmarks
- Phase 3: optional hardware bridge for non-invasive plant sensors and low-power radios
- Phase 4: evidence-backed ecological research collaborations

Principle: **Life is not the fuel to be consumed. Life is the environment the network must protect.**
